How RSA Works
RSA (Rivest–Shamir–Adleman) is an asymmetric cryptographic algorithm based on the mathematical difficulty of factoring the product of two large prime numbers. It uses a key pair: anything encrypted with the public key can only be decrypted with the corresponding private key.
🔢
1. Choose Primes
Pick two large secret primes p and q. Compute n = p × q (the modulus)
📐
2. Compute φ(n)
Euler's totient: φ(n) = (p-1)(q-1). This stays secret.
🌐
3. Public Key
Choose e (usually 65537). Public key = (e, n). Share with everyone!
🔒
4. Private Key
Compute d = e⁻¹ mod φ(n). Private key = (d, n). Keep secret!
🔐
5. Encrypt
Ciphertext C = M^e mod n — using the public key
🔓
6. Decrypt
Message M = C^d mod n — using the private key
Why is it secure? Breaking RSA requires factoring n back into p and q. For 2048-bit keys, this would take longer than the age of the universe with current computers. Quantum computers could theoretically break RSA, which is why post-quantum cryptography is an active research area.

Hybrid Encryption (Real World): Modern systems (HTTPS, PGP, SSH) combine both: RSA encrypts a random AES session key, then AES encrypts the actual data. This gives you the key-exchange safety of RSA with the speed of AES.
About This Project
The original Asymmetric Encryption project is a Java CLI application that generates a 2048-bit RSA key pair, encrypts files using the public key (RSA/ECB/PKCS1Padding), saves the private key to disk, and decrypts files using the stored private key. This web demo recreates the same functionality using the browser's native Web Crypto API (RSASSA-PKCS1-v1_5 / RSA-OAEP).

☕ Java Original

Uses KeyPairGenerator (RSA-2048), Cipher (RSA/ECB), reads/writes raw bytes with Files.readAllBytes. Keys stored as PKCS8 DER files.

🌐 Web Demo

Uses crypto.subtle.generateKey (RSA-OAEP-2048/4096), crypto.subtle.encrypt/decrypt. Keys exported as PEM (SPKI/PKCS8). Runs entirely in-browser.
